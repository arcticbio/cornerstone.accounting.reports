# Cornerstone Report Runner (`crr`)

Assembles Cornerstone Management Consulting's quarterly investor report packages from property
manager exports and Cornerstone's own accounting components: a vision model labels every source
page, deterministic code resolves an output definition into a page plan and composes the PDF.

Full quickstart and operating instructions land in Phase 9 (`docs/RUNBOOK.md`).
